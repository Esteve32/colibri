# Colibri

Colibri is an experimentation playground for **Arbora OS** — a Next.js-based sandbox for exploring product ideas, workflows, and interface patterns that could power the Arbora experience.

This repository is intended as a working demo and prototyping space. Use it to test concepts quickly, validate flows, and iterate on future Arbora OS ideas before they become part of a more polished product.

## What this project is for

- Exploring new Arbora OS concepts in a fast, editable environment
- Prototyping UI and interaction patterns
- Testing CaaS-style workflows and agent-assisted experiences
- Demonstrating ideas before they are integrated into a larger platform

## Tech stack

- [Next.js](https://nextjs.org)
- TypeScript
- JavaScript
- CSS

## Getting started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

You can start editing the app by modifying `app/page.tsx`. The page will auto-update as you edit files.

## Suggested workflow

1. Pick one Arbora OS idea to explore.
2. Implement the smallest useful prototype.
3. Validate the interaction locally.
4. Refine the experience based on feedback.
5. Repeat.

## Notes

- This repo is a playground, not a final product.
- Keep changes experimental, lightweight, and easy to replace.
- Document any interesting patterns or discoveries directly in the repo as they emerge.
